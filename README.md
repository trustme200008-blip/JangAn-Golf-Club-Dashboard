# 장안 골프 동호회 지표 대시보드

스크린골프 · 코스라운드 실적을 등록하고 분석하는 동호회용 웹 대시보드입니다.
서버 없이 정적 파일(`index.html`) 하나로 동작하며, 데이터는 Google Sheets에 저장됩니다.

배포 주소: https://trustme200008-blip.github.io/JangAn-Golf-Club-Dashboard/

## 구성

- `index.html` — 전체 앱 (스크린골프 / 코스라운드 대분류 탭으로 전환)
- `Code.gs` — Google Apps Script 백엔드 소스 (Google Sheets에 붙여넣어 배포)
- `reference_screen_golf.html` — 최초 전달받은 스크린골프 전용 앱 원본 (참고용, 배포에는 사용되지 않음)

## 기능 개요

| 구분 | 스크린골프 | 코스라운드 |
|---|---|---|
| 지표 | G핸디, 페어웨이 안착률, 그린 적중률, 홀당 퍼팅수, 드라이버 비거리 (5개) | 총타수 (+코스명, 확장 가능) |
| 보기 | 개별 / 동반자 비교 / 지표 추이 / 게임 / 보고서 | 개별 / 동반자 비교 / 지표 추이 / 게임 / 순위 |
| 데이터 등록 | 관리자 모드에서 라운드 추가·수정·삭제 | 관리자 모드에서 라운드 추가·수정·삭제 |

- **선수(동호회원) 명단**은 두 탭이 공용으로 사용하며, 관리자 모드의 "선수 관리"에서 추가·삭제할 수 있습니다.
- **관리자 모드 PIN**: `0243` (index.html 안 `ADMIN_PIN` 상수에서 변경 가능)
- **코스명**은 선수별 수치가 아니라 라운드(날짜) 하나에 공통으로 붙는 정보라, 등록/수정 폼에 별도 입력칸으로 있습니다. (선택 입력)
  타이핑하면 **전국 골프장 490개소 목록**(문화체육관광부 "전국 골프장 현황", [공공데이터포털](https://www.data.go.kr/data/15118920/fileData.do) 2024-12-31 기준)이 자동완성으로 추천되고, 목록에 없는 골프장(스크린골프장, 이후 개장한 골프장 등)은 그냥 직접 입력하면 됩니다. 목록은 `index.html`의 `GOLF_COURSES` 배열(검색: `const GOLF_COURSES`)에 있습니다.
  일부 골프장은 공식 등록명이 영문이라(예: "Oak Hills컨트리클럽", "SKY72 골프클럽") 한글로 검색하면 안 나올 수 있는데, `GOLF_COURSE_ALIASES` 배열에 자주 쓰는 한글 표기(예: "오크힐스", "스카이72")를 별칭으로 추가해뒀습니다. 새로 발견되는 케이스는 이 배열에 추가하면 됩니다.
- **코스라운드 게임(스크래치 게임)**: 최근 5회차(기록이 5회 미만이면 있는 만큼) **총타수 평균**을 기준으로, 가장 낮은 평균 선수가 스크래치(0타)이고 나머지는 그 차이만큼(반올림) 타수를 받습니다. 선택한 플레이어 기준 1:1 타수 차이도 함께 보여줍니다.
  특정 회차 값이 0이거나 기록이 없으면 그 회차는 건너뛰고 더 이전 회차 값을 가져와 유효한 값 5개(가능한 만큼)로 평균을 계산합니다.
- **새 라운드 알림**: 사이트를 열어둔 상태(탭이 보이는 상태)에서 다른 관리자가 스크린골프/코스라운드를 추가하면, 45초 주기로 자동 확인해 오른쪽 위에 토스트 알림을 띄우고 화면을 새로고침 없이 갱신합니다. 탭이 백그라운드에 있으면 확인을 멈췄다가, 다시 보이면 즉시 한 번 확인합니다. (삭제는 조용히 동기화만 하고 알리지 않습니다.) 사이트를 완전히 닫은 상태에서는 알림이 오지 않습니다 — 그 경우엔 브라우저 푸시 알림 등 별도 방식이 필요합니다.
- 데이터는 Google Sheets에 저장되어, 링크를 여는 모든 사람이 같은 데이터를 봅니다.
- 시트 연동이 안 되어 있거나 오프라인이어도, 화면 조회 자체는 그대로 동작합니다(등록만 이 브라우저에만 저장됨).
- **스크린골프 스코어 카드 (관리자 전용)**: 스크린골프 → 개별 화면 맨 아래, **관리자 모드에서만** 보이는 별도 섹션입니다.
  기존 5인 공동 라운드 데이터(G핸디 등)와 별개로, 선수 개인이 실제로 플레이한 세션(날짜 · 골프코스 · 타수)을 자유롭게 기록합니다.
  "+ 붙여넣기로 추가" 버튼으로 골프 앱/사이트의 스코어 카드 화면을 그대로 복사해 붙여넣으면 날짜·코스·타수 줄을 자동으로 인식해 미리보기를 보여주고,
  확인 후 추가하면 구글 시트("ScreenScoreCard" 탭)에 저장됩니다. 연도 선택 드롭다운으로 연도별 기록을 필터링해서 볼 수 있고, 관리자 모드에서 항목별 삭제도 가능합니다.
  같은 날짜에 여러 번 플레이할 수 있어(코스가 다름) 날짜만으로는 구분하지 않고 기록마다 고유 id를 부여해 관리합니다.

## 코스라운드 지표 확장 방법

`index.html`의 `COURSE_METRICS` 배열(검색: `const COURSE_METRICS`)에 항목을 추가하면
카드 / 표 / 그래프 / 등록폼이 전부 자동으로 반영됩니다. 현재는 총타수 1개만 들어있고, 예를 들어 핸디·퍼팅수를 더 추가하려면:

```js
const COURSE_METRICS = [
    { key: 'score', label: '총타수', unit: '타', decimals: 0, color: 'emerald', better: 'low', default: 90, icon: '...', desc: '18홀 기준 총타수' },
    { key: 'handicap', label: '핸디', unit: '', decimals: 1, color: 'blue', better: 'low', default: 1.0, icon: '...', desc: '...' },
    { key: 'putts', label: '퍼팅수', unit: '개', decimals: 0, color: 'amber', better: 'low', default: 32, icon: '...', desc: '18홀 총 퍼팅수' }
];
```

(핸디 항목은 삭제하지 않고 `index.html` 안에 주석으로 예시를 남겨뒀으니, 나중에 다시 쓰고 싶으면 주석만 풀면 됩니다.)

- `color`는 `emerald / blue / teal / amber / purple` 중에서 고르면 기존 디자인과 바로 어울립니다.
- `better`는 `'low'`(낮을수록 우수, 예: 핸디) 또는 `'high'`(높을수록 우수)로 순위 정렬 방향을 결정합니다.
- `default`는 등록 폼에 처음 보여줄 기본값입니다(생략 가능).
- Google Apps Script(`Code.gs`) 쪽은 **수정할 필요가 없습니다** — 새 지표 필드가 들어오면 시트에 열을 자동으로 추가합니다.

## Google Apps Script 백엔드 배포 (필수 — 아래 안내대로 한 번 재배포해주세요)

기존에 스크린골프 앱에 연결해두신 Google Apps Script 프로젝트가 있을 텐데, 이번에 코스라운드 ·
선수명단 기능이 추가되면서 백엔드 스크립트도 함께 업데이트해야 합니다. **`Code.gs` 파일 내용을
기존 프로젝트에 덮어써서 재배포**해주세요 (자세한 순서는 `Code.gs` 파일 상단 주석 참고).

핵심 순서만 요약하면:
1. 기존 Google 스프레드시트 열기 → 확장 프로그램 > Apps Script
2. 코드 전체를 `Code.gs` 내용으로 교체 → 저장
3. 배포 > 배포 관리 > 기존 배포 편집(연필 아이콘) > 버전: **새 버전** > 배포
   (반드시 "새 배포"가 아니라 기존 배포를 **편집**해야 `index.html`에 이미 넣어둔 웹앱 URL이 그대로 유지됩니다)

재배포 전까지는 스크린골프 화면은 기존과 동일하게 동작하지만, 코스라운드 데이터는
구글 시트에 저장되지 않고 이 브라우저에만 임시로 남습니다(재배포 후 정상 연동).

> ⚠️ **라운드 삭제 기능을 새로 추가했습니다.** 이미 Apps Script를 배포해두셨더라도,
> 삭제가 구글 시트에도 반영되려면 위 순서대로 `Code.gs`를 다시 붙여넣고 한 번 더
> 재배포해주셔야 합니다. 재배포 전까지 삭제 버튼은 이 브라우저에서는 정상 동작하지만,
> 시트의 데이터는 지워지지 않고 남아있습니다.

> ⚠️ 개발 중 관리자 모드 테스트를 위해 로컬(localhost) 환경에서 실제 연동된 시트에
> `테스트`라는 이름의 선수를 추가하는 요청을 한 번 보냈습니다. 기존(구버전) 스크립트는
> 이 요청 형식을 이해하지 못해 정상 반영되지 않았을 가능성이 높지만, 확인 차 시트에
> 이상한 행이 없는지 한번 살펴봐 주세요.

> ⚠️ **스크린골프 스코어 카드 기능을 새로 추가했습니다.** 재배포 전까지는 "붙여넣기로 추가"로
> 등록한 기록이 이 브라우저에만 저장되고 구글 시트("ScreenScoreCard" 탭, 자동 생성됨)에는
> 반영되지 않습니다. 위 순서대로 `Code.gs`를 다시 붙여넣고 재배포해주셔야 다른 기기/브라우저에서도
> 같은 스코어 카드가 보입니다.

기존 스크린골프 데이터가 쌓여있는 시트 탭 이름은 **"Rounds"**입니다 (`Code.gs`의
`SHEET_NAMES.screenGolf`에 이미 반영되어 있습니다). 만약 재배포 도중 이름이 달라
"ScreenGolf"라는 빈 탭이 자동으로 하나 생겼다면 사용되지 않는 탭이니 삭제하셔도 됩니다.

## 로컬에서 미리보기

```bash
python -m http.server 8000
```
후 `http://localhost:8000/index.html` 접속.

## 배포(GitHub Pages)

`main` 브랜치에 푸시하면 GitHub Pages가 자동으로 반영합니다 (Settings > Pages, 브랜치: `main`, 폴더: `/`).
